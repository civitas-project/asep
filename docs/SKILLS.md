# SKILLS — Canonical Skill Index

Activation rules, mandatory constraints and skill discovery live in the single canonical
Core Protocol: [`protocol/CORE.md`](../protocol/CORE.md). Native entry points
(`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`) are generated from it. No bootstrap or router is
required to start a task; load a domain skill only when its scope matches the task.

## Ambient domain skills

## Generated copies (do not edit)

Copies under `.opencode/skills/`, `.agents/plugins/asep/skills/`, and
`crates/spec-engine/.agents/plugins/spec-engine/skills/` are generated by `asep pack`.
These directories are gitignored and must not be edited directly. Edit the canonical
source, then regenerate. `asep init` regenerates the native entry-point blocks and writes
`protocol/CORE.md` from the embedded canonical text; it removes stale mandatory
router/bootstrap entries on upgrade without deleting existing files.

## Embedding and drift guard

`crates/spec-engine/src/pack/embedded.rs` embeds canonical skill text via `include_str!` and
embeds `protocol/CORE.md` as `CORE_PROTOCOL`. `AMBIENT_SKILL_IDS` selects the five skills
installed by default. `asep check` drift detection verifies generated copies match the
canonical text.
